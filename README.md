This project takes part from Innovation Fest Event, and was developed with a team, working to build a robotic arm \& smart glove using Mega and Nano Arduino microcontrollers incorporating electric components (motors and sensors) to enable mechanical movement and responsiveness.



Components:

* Flex sensor
* Accelerometer
* Joystick module
* Servo motors
* Stepper motor
* L298N Dual Bridge DC \& Stepper Motor Controller Board
