## Overview
This project takes part of Innovation Fest 2024, and was developed with a team, working to build a robotic arm \& smart glove using Mega and Nano Arduino microcontrollers incorporating electric components (motors and sensors) to enable mechanical movement and responsiveness.

## Features
* Robot arm claw responds accordingly to the flexing behaviour of the fingers
* Robot arm wrist rotation movement responds to the rotational motion of captured from the accelerometer based user wrist rotation
* Robot arm Elbow and shoulder moves accordingly based on positional motion from accelerometer readings

## Components
* Flex sensor
* Accelerometer
* Joystick module
* Servo motors
* Stepper motor
* L298N Dual Bridge DC \& Stepper Motor Controller Board

## Technologies
* Arduino IDE
* FreeCAD

## Project Structure
* Source code is found in src_robot_arm.ino
* Images file contains both CAD pdfs including components sketches with their dimensions, project logo and prototype sketches.
